# Reading, Writing, and Using a Concept: Three Directions in the Residual Stream

**Mechanistic interpretability of an open-source LLM — reproduction and extension of _On the Biology of a Large Language Model_.**

Iuliia Vitiugova — MPhil in Data Intensive Science, University of Cambridge
Model: **Qwen3-4B** (base) with pre-trained per-layer transcoders (`mwhanna/qwen3-4b-transcoders`).

- **Full report:** [`report/report.pdf`](report/report.pdf)
- **Executive summary (851 words):** [`report/executive_summary.pdf`](report/executive_summary.pdf)

## Summary

A linear probe shows that a concept is *decodable* from a model's hidden states, not that the decoded
direction is the one the model *uses* to compute its answer. On a controlled binary task (classifying
nuclear decay as alpha or beta) this project shows that the single notion of a "concept direction"
separates into three geometrically and causally distinct objects, measured per layer at the answer position:

- **reading direction** `w_LDA` — the Fisher discriminant, the optimal linear readout of the class;
- **writing direction** `Δμ` — the difference of class means, the contrast written into the residual stream;
- **use direction** `u` — the class-averaged gradient of the logit margin, the direction the output is locally most sensitive to.

The central finding is a **double dissociation**: the reading direction decodes the class at held-out AUC
0.98–0.99 yet intervening along it leaves the answer unchanged, while the projection onto the use direction
decodes barely above chance at the very layers where intervening along it reverses the class margin on most
examples. The inertness is geometric, not universal: on the particle pairs, where the reading direction has
a larger component along `u`, the same intervention flips the answer. The writing direction is built by the
MLP blocks, lies in the span of the transcoder features well above a random null, and carries physical
properties of the decay (charge, lepton number, nuclear composition, transition type) rather than the class
label, from which the class is assembled in a late decision zone.

## Environment

```bash
conda env create -f environment.yml      # Python 3.10
conda activate qwen-circuits
# or, with pip:
python -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt
```

Experiments were developed and run on the **CSD3** high-performance computing cluster. GPU stages load
Qwen3-4B and the transcoders; the analysis and plotting stages are pure NumPy/scikit-learn and run on CPU.

## Data availability

The small prompt corpora are included under `data/prompts/`. The large intermediate artefacts — per-layer
residual and gradient dumps (`res_L*.npy`, `grad_L*.npy`), the model weights, and the transcoder dictionary
— are **not** committed (see `.gitignore`) and are regenerated by the capture stage or downloaded from their
public sources: Qwen3-4B from Hugging Face and the transcoders from `mwhanna/qwen3-4b-transcoders`.

## Reproducing the results

The pipeline is a sequence of numbered scripts; representative stages:

| stage | script | output |
|---|---|---|
| baseline | `scripts/02_run_baseline.py` | answer-position fixing, class margins |
| transcoder features | `scripts/04_extract_transcoder_features.py` | active features per prompt |
| attribution graph | `scripts/06_build_attribution_graph.py` | feature-to-feature graph |
| interventions | `scripts/07_run_interventions.py`, `scripts/14_path_validation.py` | ablation / patching effects |
| field dump | `scripts/119_capture_field_dump.py` | per-layer residual + gradient dumps |
| decodability | `scripts/check_decodability_by_layer.py` | `results/geometry/decodability_by_layer.csv` |
| direction geometry | `scripts/axis_geometry_by_layer.py` | `results/geometry/axis_geometry_by_layer.csv` |
| feature span | `scripts/110_active_span_triad.py` | `results/geometry/active_span_triad.csv` |
| whitening identity | `scripts/133_whitening_theorem.py` | `results/geometry/whitening/` |
| steering sweep | `scripts/122_b1_steering_sweep.py`, `scripts/85_steering_all_layers.py` | `results/steering/` |
| steering summary | `scripts/steering_summary_table.py` | `results/steering/steering_summary_all.csv` |
| clustering | `scripts/22`–`29`, `scripts/27*` | HAC clusters + acceptance criteria |

See each `results/*/README.md` for the exact thesis-number-to-file mapping.
